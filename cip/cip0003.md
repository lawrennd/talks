# CIP-0003: AI and Security Talk for Startup: From Bandwidth to Practical Security Implications

## Summary

This CIP outlines the creation of a high-level, discussion-oriented talk on AI and Security for a startup audience. The talk will begin with the bandwidth concept and new flow of information, introduce the Human Analogue Machine, then explore practical security consequences split into classical security and GenAI security, with a focus on Trent's progression from classical security using GenAI to GenAI security and wider information systems implications.

## Motivation

This talk is needed to:

1. **Startup Context**: Provide high-level strategic thinking for a new startup in the AI/security space
2. **Audience Engagement**: Create an half hour-long talk that has plenty of interaction so lasts an hour with the interaction.
3. **Conceptual Foundation**: Establish the bandwidth and information flow concepts as foundational understanding
4. **Practical Application**: Bridge theoretical concepts to practical security implications
5. **Progressive Complexity**: Structure content to move from classical to GenAI security challenges
6. **Strategic Vision**: Help startup understand the broader implications for information systems

## Detailed Description

The talk will be structured in seven key sections:

### 1. Three Practical Security Examples (Opening)
- **Classical Security Example**: Heathrow/Brussels airport cyber-attack on Collins Aerospace systems (BBC News, 2025) - demonstrates traditional infrastructure vulnerabilities <https://www.bbc.com/news/articles/cwy88857llno>
- **New Attack Front Example**: Notion AI Agents - shows emerging GenAI security challenges and HAM vulnerabilities <https://www.codeintegrity.ai/blog/notion>
- **Personal Example**: [Twitter/X example from lawrennd] - illustrates real-world impact and decision-making <https://x.com/lawrennd/status/1962049775693394067>
- These examples set the stage for understanding the evolution from classical to GenAI security challenges

### 2. Bandwidth and New Flow of Information
- Human bandwidth limitations in digital systems
- How information flows have fundamentally changed
- The disconnect between human cognitive capacity and digital system capabilities
- Setting the foundation for understanding security challenges

### 3. The Human Analogue Machine (HAM)
- Introduction of HAM as a new interface paradigm
- Moving beyond traditional digital computer interfaces
- HAM as a bridge between human intelligence and digital computation
- **Ross Anderson's insight**: Humans are always the weak link in security chains
- **HAM as "humans scaled up"**: Amplifies both capabilities and vulnerabilities
- **CodeIntegrity Notion example**: Demonstrates how HAM creates new attack vectors
- Implications for how we interact with AI systems

### 4. Classical Security in the AI Era
- Traditional security challenges amplified by AI
- How GenAI tools can be used to enhance classical security
- Attack vectors that emerge from AI-enhanced capabilities
- Defensive strategies using AI for classical security problems

### 5. GenAI Security Challenges
- New security challenges unique to generative AI systems
- Prompt injection and manipulation attacks
- Model extraction and intellectual property protection
- Adversarial examples in the generative context
- Data poisoning in training pipelines

### 6. Trent's Security Evolution
- **Phase 1**: Classical security enhanced with GenAI tools
- **Phase 2**: Security challenges specific to GenAI systems
- **Phase 3**: Broader implications for information systems architecture
- Strategic progression for startup focus areas

### 7. Wider Implications for Information Systems
- How security thinking must evolve for AI-native systems
- Information architecture changes required
- Trust and verification in AI-mediated interactions
- Future-proofing security strategies
